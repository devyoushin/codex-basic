# Command Rules

## C1. 검색 우선

- 텍스트/심볼 검색은 `rg` 우선
- 파일 목록은 `find` 또는 `rg --files` 우선

## C2. 출력은 필요한 만큼만

- 큰 파일은 `sed -n '1,200p'`처럼 필요한 구간만 읽기

## C3. 파괴적 명령 금지(요청 없으면)

- `rm`, `git reset --hard`, 대량 삭제/이동은 사용자 요청 없이는 금지

## C4. 명령은 목적이 명확해야 함

- “왜 실행하는지/무엇을 확인하는지”가 불명확한 명령 실행 금지

## C5. 네트워크/원격 접근 감각

- 원격 접근(`git push`, 패키지 다운로드 등)은 환경에 따라 승인(에스컬레이션)이 필요할 수 있음
- 원격 작업 전/후로 `git status --porcelain=v1`로 변경 상태 확인
