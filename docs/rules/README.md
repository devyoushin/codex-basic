# docs/rules/ — Codex 운영 규칙

이 폴더는 Codex를 “안전하고 예측 가능하게” 쓰기 위한 규칙 모음입니다.

## 규칙 목록

- `command-rules.md` — 쉘/검색/조회 원칙
- `patch-rules.md` — `apply_patch` 패치 원칙
- `testing-rules.md` — 테스트/검증 원칙
- `repo-rules.md` — git/브랜치/커밋 원칙
- `communication-rules.md` — 응답 스타일/질문 방식
- `safety-rules.md` — 승인/권한/보안

새 규칙을 추가하면 이 파일에 목록을 갱신합니다.
